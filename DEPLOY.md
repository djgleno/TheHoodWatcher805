# The Hoodwatcher 805

Independent Central Coast news and public-accountability reporting, developed under the GreenEdge Media Group name.

## Status
Initial static landing page. The news archive, review queue, automated collection and hosting deployment are **not yet live**.

## Free deployment
1. Sign in to Cloudflare.
2. Workers & Pages → Create → Pages → Connect to Git.
3. Authorize Cloudflare to access this repository.
4. Select `djgleno/TheHoodWatcher805`.
5. Set framework preset to **None**, build command blank, and output directory to `/` (repository root).
6. Deploy. Choose `thehoodwatcher805` as project name if available.

Do not publish private source records, credentials, or unverified allegations. Review news copy, attribution and source links before publication.
